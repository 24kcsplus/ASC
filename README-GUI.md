# ASC Workbench · v0.2

基于 [MG1937/ASC](https://github.com/MG1937/ASC) 的 PySide6 / Qt 6 桌面前端，采用 JADX 风格的类树、代码标签、方法结构与搜索结果工作区。上游基线：`47663fd4ef680af223aef0d22b308270b217ec46`。

## 启动

当前交付目录已配置独立 `.venv`，直接运行：

```bash
/mnt/tiplus7100/ctf/tools/asc_newgui/run-gui.sh
# 也可以启动时打开 APK；相对路径按调用者当前目录解析
/mnt/tiplus7100/ctf/tools/asc_newgui/run-gui.sh /path/to/app.apk
```

支持拖入 APK、文件选择和最近打开列表。无需浏览器或本地 HTTP 服务。

重新安装依赖（Python 3.10+；本机验证为 Python 3.12 / Linux）：

```bash
./install-gui.sh
# 网络需要镜像时
PIP_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple ./install-gui.sh
```

## 已实现

- 深色 / 浅色主题、可停靠侧栏、可移动标签，以及保存窗口布局和主题。
- 起始页与菜单显示最近 12 个 APK，包含完整路径，支持重启恢复、单条移除、清空记录和失效文件提示。
- 包树按展开创建节点；按类名或包名过滤；双击打开真实反编译源码。
- Java / XML 语法高亮，区分类/类型、方法、关键字、数字、字符串、注释与注解；同名标识符高亮会避开字符串和注释。
- 行号、当前行、括号配对、文件内搜索高亮、跳行、代码字体缩放和源码导出。
- 双击代码中的类或方法，或按 F3 / 右键「跳转到定义」；多候选和重载显示签名选择列表。
- 双击局部变量定位声明行；双击函数参数定位所属函数签名中的参数声明，并选中变量名。
- 方法结构显示参数签名并支持跳转；前进 / 后退恢复光标、选区与滚动位置；中键关闭标签。
- Manifest 查看；字符串、类型、方法、字段引用搜索；方法 / 字段名称检索。
- 方法 / 字段引用搜索可限定类名，也可选择模糊类名。
- 搜索结果流式显示、结果过滤与排序、双击打开类。
- 分析引擎独立进程，耗时任务不会直接占用 Qt 主线程；异常信息展示在状态栏和日志中。

## X 交叉引用

代码区将光标放到方法、字段、类型或字符串上，或选中该符号，按 `X` 即可发起对应引用搜索。右键菜单也提供「查找交叉引用」。该快捷键仅在代码区生效，不影响搜索框输入字母 x，也不占用 Ctrl+X。

代码区默认按所属类精确查询：

- 方法、字段：从 `this`、参数、局部变量或字段链确定所属类，精确匹配 DEX 类描述符和成员名，避免其他类的同名成员及 `a` / `ab` 包含匹配。方法结合参数数量筛选，同类同参数数量的重载仍可能合并，结果展示参数类型。
- 类名：汇总对该类的直接类型引用，以及对该类方法、字段的访问；包括其他类通过该类实例发起的调用。
- 结果中的「所属类」是被引用成员所属类；调用位置可位于 APK 中其他类，不会仅搜索当前文件。
- 无法唯一确定所属类时提示手动指定，不自动退回全局名称搜索；局部变量不具备 DEX 成员引用。
- 右键「全局按名称查找引用…」保留原名称搜索；手动搜索面板仍沿用 ASC 的名称/包含匹配。字符串引用保持原查询方式。

查询基于静态 DEX 引用，不区分同一类的不同运行时实例，不追踪反射或完整虚方法动态分派。继承成员会查询可解析的声明类及接收者类；尚未穷举全部子类/接口实现的引用别名。

## 双击跳转与最近打开

双击 Java 代码中的类名或方法名即可尝试进入定义。方法查询会核对 DEX 中的真实定义、所属类和参数数量，再按方法签名定位反编译源码行。优先解析参数/局部变量的有效声明类型，以及 DEX 中的字段类型（含 `this.field`、字段链和继承字段），再在所属类、父类或接口内查找。局部变量优先于同名字段和混淆类名；静态调用按完整类名、导入和当前包确定范围，不自动汇集其他包的同名类。存在重载时显示限定范围内的签名列表。APK 中没有定义的系统库/外部依赖会显示提示。方法声明名称处双击只选词，不发起定义查找；调用处继续支持双击跳转，声明处仍可按 X 查看引用。按住 Ctrl 双击可保留普通选词操作。

无法确定接收者时只提示，不再自动扫描全 APK 的同名方法；已确定类型但没有 APK 内定义时也不会全局回退。需要按名称扩大查找时，在调用的方法名上右键选择「全局查找同名方法定义…」，该结果会明确标注为全局候选，始终由用户选择。`X` 是独立的引用查询，现默认精确限定所属类和成员名。

跳转后按 Esc 或 Alt+Left 返回调用处，Alt+Right 再次前进；光标、选区、垂直和水平滚动位置都会恢复。关闭某个标签会从当前浏览历史中移除该标签的记录。Esc 在查找栏打开时先关闭查找栏，再按一次返回；弹窗内优先关闭弹窗。在起始页按 Esc 返回最近的代码界面，没有历史时不执行跳转。

顶部「起始页 / 最近打开」进入最近文件列表，双击文件即可打开。「返回代码」回到当前代码标签。最近记录立即保存，清空和移除操作只影响记录，不删除 APK。

## 变量与参数跳转

在变量使用处双击，或将光标放在变量上按 F3：

- 函数参数（如 `p1`、`p2`）：跳到所属函数签名中的参数声明。
- 局部变量（如 `v0_1`）：跳到有效代码块中的变量声明行。
- 目标变量名会被选中；Alt+Left / Alt+Right 返回使用处或再次前进。

查找限定在当前函数和有效块作用域内，处理常见的 for / catch / try 资源声明，不把其他函数中的同名变量、普通赋值、注释或字符串当作声明。当前是源码文本解析；无法可靠确定 lambda、局部类或捕获变量作用域时不进行变量跳转。类字段不属于本轮局部变量解析范围。

## 当前版本范围

这是能接入真实 APK 的 Qt 桌面工作区，尚未覆盖完整 JADX 功能。

- 源码只读；不包含注释持久化、重命名、Smali、调试器、完整资源浏览和代码折叠。
- 方法结构和源码行定位使用文本解析，结合 DEX 定义查询；不是完整 Java 语义解析器。尚不推断方法返回值链（如 `factory().a()`）、数组元素、强制转换表达式、完整泛型和运行时动态分派；这些接收者无法确定时提示手动查找，找不到源码行时会停留在目标类并提示。
- X 引用结果仍定位到类，尚未实现精确调用指令到源码行的映射。
- 全局检索使用 ASC 原有引用 / 成员查询，不提供所有反编译源码的全文搜索。
- 一次处理一个前台分析请求；处理期间可以阅读已有标签，新的类加载或搜索需要等待。关闭窗口会终止本会话的分析进程。
- 沿用上游 GUI 的全 DEX 加载方式，包树懒展开不等于 DEX 按需加载。后台源码缓存最多 32 个类，已打开的代码标签仍持有各自文本。
- 引用 / 成员结果最多显示 5,000 条；类名过滤最多显示 2,000 条，界面显示限制，请缩小查询范围。
- 当前交付为 Linux 源码与独立 Python 环境，尚未制作 Windows / macOS 安装包。

## 代码结构

- `asc_gui/app.py`：主窗口、工作区与异步消息连接。
- `asc_gui/editor.py`：源码阅读器、行号与语法高亮。
- `asc_gui/models.py`：搜索结果数据模型。
- `asc_gui/navigation.py`：源码符号、参数签名和声明位置解析。
- `asc_gui/variables.py`：函数参数、局部变量和有效块作用域的声明定位。
- `asc_gui/definitions.py`：共享 DEX 所属类/字段链解析，查询真实方法定义及继承候选。
- `asc_gui/references.py`：精确成员引用、类及其成员的引用汇总，复用 ASC 指令扫描器。
- `asc_gui/theme.py`：深浅主题。
- `asc_gui/worker.py`：常驻分析进程，通过 JSON Lines 与 Qt 通信，复用原 `GuiDexStore`。
- `src/`、`main.py`：原 ASC 后端和旧 GUI；保留原启动入口。
- `tests/gui/smoke.py`：真实 APK 的 Qt 集成验证与截图生成。
- `tests/gui/test_navigation.py`：双击跳转、重载选择、历史位置恢复、最近记录和高亮验证。
- `tests/gui/test_xref.py`：X 快捷键和引用查询回归验证。
- `tests/gui/test_scoped_references.py`：所属类/成员名精确过滤及真实 APK 的 X 查询验证。
- `tests/gui/test_receiver_scope.py`：接收者所属类、字段链、继承与禁止隐式全局扫描，以及真实 Qt 方法跳转验证。

运行验证：

```bash
QT_QPA_PLATFORM=offscreen .venv/bin/python tests/gui/smoke.py \
  /path/to/app.apk --class-name 'Lyour/package/MainActivity;' \
  --output /tmp/asc-gui-check
```

不运行 APK，只对其内容进行静态读取和反编译。验证截图位于 `screenshots/`，测试结果见 `VALIDATION.md`。
